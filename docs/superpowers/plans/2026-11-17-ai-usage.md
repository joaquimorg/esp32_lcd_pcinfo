# Uso das subscrições de IA — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sensores e widget "Uso de IA" com a utilização das janelas do Claude Code e do Codex e a hora de reset.

**Architecture:** `src/main/ai-usage.js` consulta os serviços (90 s, só leitura dos logins) e entrega sensores `ai/<serviço>/<primary|secondary>` que `Sensors.tick()` junta à lista. Um tipo de propriedade novo `sensorGroup` entrega ao widget todos os sensores de um serviço. Widget `widgets/aiusage/`.

**Tech Stack:** Electron 44, Node `fetch`, `node --test`, widgets HTML + `widget-sdk.js`.

**Spec:** `docs/superpowers/specs/2026-11-17-ai-usage-design.md`

## Global Constraints

- Nunca usar `refreshToken`/`refresh_token`, nunca escrever em `~/.claude` ou `~/.codex`, nunca registar tokens, e-mail ou id da conta.
- Consulta a cada 90 s; 429/5xx → dobra até 600 s.
- `config.ai = { claude: false, codex: false }` por omissão.
- Claude: `GET https://api.anthropic.com/api/oauth/usage`, `Authorization: Bearer`, `anthropic-beta: oauth-2025-04-20`; `five_hour` (18000 s) → primary, `seven_day` (604800 s) → secondary.
- Codex: `GET https://chatgpt.com/backend-api/wham/usage`, `Authorization: Bearer`, `chatgpt-account-id`; `rate_limit.primary_window`/`secondary_window` (`used_percent`, `limit_window_seconds`, `reset_at` em s).
- Textos novos em `src/i18n.js` em EN e PT (o teste de i18n exige as mesmas chaves).

## Review Focus

- Ficheiro de login ilegível ou JSON parcial (o Claude Code está a escrevê-lo) → estado de erro, sem rebentar o ciclo de sensores.
- Claude `expiresAt` no passado → nenhum pedido; estado `expired`.
- `secondary_window: null` → só o sensor primary; o widget ocupa o espaço com uma janela.
- `resetAt` já passado com 100% (dados velhos) → o widget mostra "reset agora", nunca tempo negativo.
- Serviço desligado depois de ligado → sensores desaparecem e o widget mostra "sem dados".

### Task 4: Widget `aiusage`
